Describes the font used to render text.

Description

Describes the font used to render text. Every font consists of a font family (like Source Sans Pro), a weight like FontWeight.Bold, and a style like FontStyle.Italic.

Font families are a type of asset, like images or meshes. Each font family contains a number of font faces, and each face has a different weight and style.

Font is used by the TextLabel.FontFace, TextButton.FontFace, and TextBox.FontFace properties.

fromName

TODO:PARAMETERS

This is a convenience method for creating fonts from the content folder. The name you pass in will be converted into an asset ID like rbxasset://fonts/families/YourFontNameHere.json.

The name can only contain alphabetical characters, digits, _ (underscore), and - (hyphen). It can't contain any spaces.

Properties 4

Family

Content

The asset ID for the font family. These start with either rbxasset:// or rbxassetid://.

Weight

FontWeight

How thick the text is. The default value is FontWeight.Regular.

When set, Font.Bold is updated. Bold is true if the weight is FontWeight.SemiBold or thicker.

Style

FontStyle

Whether the font is italic. The default value is FontStyle.Normal. The font can be made italic (like this) using FontStyle.Italic.

Bold

bool

Whether the font is bold. Sets Font.Weight to FontWeight.Bold when true, and FontWeight.Regular otherwise.
